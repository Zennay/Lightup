Recommended / Encrypted HUMAN workspace vault

This optional AES-256-GCM vault encrypts the exact source-bound workspace in browser memory using PBKDF2-SHA256 (600,000 rounds), a fresh salt and nonce. It is bound to the two hashes of the imported original CSV but never proves sender identity, consent, evidence or scope authorization. Losing the passphrase prevents restore.

An encrypted vault can be decrypted only with the original exact CSV bytes and the right passphrase. The contents remain HUMAN-only, never authoritative. No plaintext intermediate file is created when saving or opening the encrypted version.
