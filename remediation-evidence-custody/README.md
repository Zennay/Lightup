## Delivered
- Imports unmodified original PRIVATE Artifact Ledger v1 or Unified HUMAN Workspace v2 JSON with a 2 MiB ceiling. **Before allowing any comparison or export, it now requires an independently obtained original five-column findings CSV**: uses the exact unchanged original `casework/remediation-engine.js` parser (source SHA-256 pinned), recomputes canonical full-record SHA-256, checks count and every attached original finding identity. Imports stay local and in memory.
- Compares up to 240 locally picked evidence files (16 MiB each) against indexed original finding ID + local file SHA-256 + length. WebCrypto hashes file bytes locally. Distinguishes exact byte/label agreement, byte agreement with changed labels, original index entries absent from the locally selected file set, same label with different bytes, duplicate selected local copies of already-indexed bytes (not falsely counted as unindexed), and truly unindexed or oversize local files. It also identifies every original finding that has **zero local artifact index entries**, even when no local files were selected for hashing; this is a LOCAL coverage gap, not proof of actual missing evidence or a security finding.
- Supports optional local folder selection where the browser provides directory picking, plus searchable, status- and original-severity-claim-filtered HUMAN comparison rows sorted by LOCAL attention status then original unverified severity. Critical/high source-label attention receives separate counts without claiming actual exposure or a successful retest. Automatically invalidates comparisons on any input-file or manifest change, preventing a stale export after a new selection.
- Handles a single local matching file referenced by several original findings without claiming it has independent provenance for each one. Missing from the selection is not evidence missing on another machine or proof of remediation.
- Exports separate **anonymous counts-only CSV** (no source/ID/name/hash; includes only count of original high/critical source-labelled LOCAL attention) and a user-confirmed **PRIVATE HUMAN source-bound CSV** with finding IDs, SHA-256 and filenames. Spreadsheet formula-style values (including Unicode compatibility-form operators, whitespace, BOM, zero-width or bidi prefixes) are escaped while leaving original labels unchanged. All text remains HUMAN-only observations, never cryptographic authenticity, security verification or custody signature.
- Offers preserve-first **original HUMAN request merge**, instead of blindly exporting replacement drafts. The original Unified HUMAN v2 PRIVATE input brings its entire native request baseline (preserved unchanged); optional original Request Desk v1 PRIVATE packet can supply the baseline when a standalone Artifact Ledger v1 is used. If two baseline sources conflict, HOLD. If none is supplied, explicit operator empty-desk acknowledgement is required. Every original owner HUMAN request ID/status/notes is retained, new questions arise only for original findings with no locally indexed evidence, or local byte/label mismatches, without an existing open request for that finding; native 200-request cap is enforced atomically. Shows a private count preview before separately confirmed export of exactly original Request Desk v1 JSON. Original owner desk STILL checks original source and requires independent manual replace-all import confirmation; no automated native Apply.
- Clears sensitive records from the tab with Forget. Does not send, upload or persist evidence bytes and does not modify an original owner application.
