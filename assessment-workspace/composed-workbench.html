02 / ORIGINAL COMPLETED LAB SOURCES ONLY

One private review handoff command

For two **already-completed** original lab benchmark source files, one command runs the existing original comparator and creates six private outputs, without calling any lab runner or target:

python3 scripts/lightup_composed_review.py \
  /private/BASE-completed-case.json /private/NEXT-completed-case.json \
  --output-dir /private/reviews \
  --prefix review01

This produces an original comparator review ZIP, unchanged canonical comparison JSON with source-owner metrics and REVIEW_ONLY/HOLD, an archive manifest, interactive source-bound Studio, editable human draft and private review-room ZIP. Genuine metric-regression HOLD remains visible for human investigation and never becomes clearance.

Destination must be an existing privately owned 0700 directory. Files are new, 0600 and never overwritten; measured original regression results remain HOLD, not an implied clearance. For existing cohort-array inputs add --cohort.

Original case files can also be selected individually (1–64 on each side), without manually preparing cohort arrays:

python3 scripts/lightup_workbench.py compose   --baseline-case /private/BASE1.json   --baseline-case /private/BASE2.json   --candidate-case /private/NEXT1.json   --candidate-case /private/NEXT2.json   --output-dir /private/reviews --prefix batch01

Uses original source-owner cohort bundling and comparison. Adds two private original cohort array exports beside the six normal outputs; no target work or consent.
