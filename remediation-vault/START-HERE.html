Private collaboration flow

1. Start with original sourceObtain original files through independently authenticated, authorised channels.
2. Coordinate human workOpen Evidence, Calendar and Dependency tools independently against the exact same engagement.
3. Prepare owner returnSend a source-bound owner packet privately; preview and accept separately inside the original workflow.
4. Encrypt minimum neededIn the Vault, choose only authorised files. Share password separately; recipient rechecks identity and scope.
Source artifacts are pinned by SHA-256 in MANIFEST.json and the packager; only unchanged, separately held original owner snapshots are included. All five applications run independently; no runtime network or shared browser storage. Cryptographic integrity does not constitute current authorisation. This workspace is not deployed to production.
