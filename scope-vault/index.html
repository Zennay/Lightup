Private packet vault

Encrypt draft scope packets into one password-protected offline file. Nothing is uploaded, sent, approved or authorized.

1. Collect local review files

Self-label each file as a client proposal, operator note, scope revision or schedule handoff for offline sorting; labels are never verified authority. Collect up to 12 draft files (.json, .md, .txt, .ics, .csv; each max 512 KiB, combined max 2 MiB). Names and file content are inside the encrypted packet, not in its public metadata. Avoid importing passwords, API keys or live customer secrets.

No files selected. Decrypt a saved vault below or collect new files.

2. Seal an encrypted packet

Each export uses a new random 256-bit AES-GCM key derived from your passphrase with PBKDF2-SHA256 (600,000 iterations). LightUp never stores, recovers, or transmits your passphrase.

3. Restore a saved packet

Load one locally saved encrypted vault. Its authenticity depends on knowing the passphrase and trusting where you got the file. Encryption alone does not prove client identity, consent, scope approval or authorization.

4. Handle review material

Files stay in tab memory only. Download a recovered original only after an explicit click. The workspace forgets plaintext when hidden or idle for five minutes.
