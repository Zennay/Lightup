# LightUp · One offline human review desk across all original agendas

**INCUBATE M3/M7 · PLAN/LAB ONLY · DRAFT/HOLD · NO GO.**

The private original human Review Studio now has a **Portfolio-wide human attention desk** above the existing per-source editor. Instead of opening each original agenda separately, the operator sees up to **12 original source agendas and 768 human-only items** in one local browser view. Every row displays only its source ordinal, original immutable source slot, source-kind category, current human stage, neutral role, proposed discussion date, whether the ORIGINAL source is in HOLD, and a badge for purely local human edits. Original client identifiers, lab targets, credentials, evidence bytes or scanner output do not enter the board.

Operators can filter across all agendas by selected original human stage, neutral next role and date bucket relative to the ORIGINAL explicit shared reference day. They can select all currently visible source slots or specific rows, then apply a selected new human stage, neutral role, proposed date or clear a human date **across different original source agendas at once**. A separate explicit human-only acknowledgement is required; original source membership, immutable source kind, HOLD, evidence, authorization and stored originals cannot be edited. An empty/invalid/stale selection, contradictory date choices, or invalid stage/role/date fails before any local mutation. Changing filters clears the previous cross-agenda selection rather than leaking a prior selection into another view.

The desk also shows the total/visible/selected/locally changed human-only counts. The old detailed single-agenda editor, prior/new human-diff pane, per-agenda private JSON export and original proposal restore all remain available and synchronized with the shared in-memory drafts. The existing **Export ALL original human proposals** always serializes the current complete source-bound state of every original agenda, including changes made across multiple source groups. From there use `workspace_return.py --proposal-bundle` to receive new original-schema choices or `review_cycle.py --proposal-bundle --next-as-of YYYY-MM-DD` to create the next full offline workspace and private revision board.

No browser storage, network, remote script, client data writes, job scheduling, source findings edits, grants, models, scanners, real target interaction, consent, retest or approval. Private original source SHA-256 values are local byte correlations, **not evidence of authenticity**. Original claims and original HOLD remain unchanged. Actual execution/release still requires mandatory original exact-head hosted/named VPS CI, source-owner and independent privacy/security reviews, real separately authenticated client+operator permission with at-use revocation, original #177/#182/#829 and explicit HUMAN GO.

The source file for this product is `assessment-portfolio/review.js` with `review.template.html`, built into the original complete standalone Review Studio by `review_studio.py`. No QA/regression/test suite is part of this product change.
