What happens next

  1. The browser downloads one URL per line; no content is uploaded or saved to browser storage.
  2. Move the file into a private local folder and set its permissions to 0600. Browser downloads cannot enforce file permissions.
  3. The native CLI re-admits the file against the pinned original validator and LabScenario scope policy, then creates private no-overwrite artifacts.
  4. The generated command contains --preview-only and is displayed for a human to inspect. This tool never executes it.

A URL passing browser syntax checks is not proof that it is an isolated lab endpoint. The original native scope gate is mandatory and may reject it. No authorization, consent or release is created.
